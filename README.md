# Dongeon（地牢求生）

中文控制台回合制地牢 RPG · C++17 · 数据驱动设计

一个从零手写的控制台小游戏，聚焦于**游戏系统设计**：数据驱动配置、多态物品体系、装备构筑、Boss 战、JSON 存档。所有怪物与物品均由 JSON 配置驱动——改配置即可调平衡，无需动代码。

## ✨ 特性一览

- **7 大区域 · 30 种怪物**：从森林到深渊之王，等级窗口重叠衔接，0~60 级全程有怪可刷
- **7 个 Boss**：10% 概率遭遇，3 倍以上属性，专属武器掉落（仅 Boss 产出）
- **完整装备构筑**：7 档武器 + 7 档防具 + 6 档药水 + 7 件 Boss 专属武器，共 27 个物品模板
- **二段成长曲线**：前期线性温和成长，40 级后二次加速——后期升级慢、每级变强明显（厚积薄发）
- **适度掉落**：普通怪 ~15% 掉装备，构筑成型有期待不白刷
- **JSON 存档**：全量序列化（属性/背包/装备栏），随时保存随时继续
- **数据驱动**：怪物/物品/掉落表全在 `config/*.json`，改数据即改游戏

## 🎮 玩法

回合制战斗：攻击 / 逃跑(50%) / 使用药水。击败怪物获得经验与掉落，升级强化属性，穿装备构筑强度。在地牢门口选择：战斗、休息回血、查看状态/背包/装备、保存、退出。

死亡可选择重新开始；存档随时手动保存。

## 🧮 数值体系（V5.0 设计）

| 项目 | 设计 |
|---|---|
| 升级经验 | `expToUp = 15 + 8×等级`（≤39 级）；`+3×(等级-39)²`（≥40 级，二次加速） |
| 属性成长 | 每级 HP+6 / 攻+1~2 / 防+1（前段）；40 级后增量随等级递增 |
| 怪物刷新 | 等级窗口 `[minLevel, maxLevel+3]`，低级怪自然退场、高级怪不断档 |
| Boss 战 | 普通怪池 10% 概率遭遇等级匹配 Boss，掉落 3 次 roll（专属武器 70% 权重） |
| 掉落 | 普通怪药水 85% / 武器 8% / 防具 7% ≈ 6~7 个怪出一件装备 |

## 🏗 构建

要求：CMake ≥ 3.20、支持 C++17 的编译器（Windows 推荐 MinGW-w64 g++）。

```bash
cmake -S . -B build -G Ninja -DCMAKE_CXX_COMPILER=g++
cmake --build build

# 运行（必须在项目根目录下启动，程序使用相对路径读取 config/ 与 save/）
./build/dongeon.exe
```

VS Code 使用：安装 CMake Tools 插件后打开本目录即可自动识别 `CMakeLists.txt`。

## 📁 项目结构

```
Dongeon/
├── dongeon.cpp            # 主入口 + 游戏主循环（菜单状态机）
├── include/               # 头文件（按模块分目录）
│   ├── Player/            # 玩家：属性/背包/装备栏
│   ├── Monster/           # 怪物 + Boss
│   ├── Item/              # 物品体系：Item 基类 + Medicine/Equipment
│   ├── Battle/            # 战斗逻辑
│   └── Config/            # 常量/配置加载/存档/UI
├── src/                   # 实现文件（与 include 对应）
├── config/
│   ├── monster.json       # 30 种怪物（含掉落表、Boss 标志）
│   └── item.json          # 27 个物品模板
├── docs/                  # 架构分析与开发感言
└── save/                  # 运行时生成的存档
```
