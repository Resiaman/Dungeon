> 方法：解析 config/*.json + 按 Player.cpp/Config.h/FightLogic.cpp/Monster.cpp 公式复算，蒙特卡洛模拟 20000 场/场景。

## ① 升级曲线（二段公式复核）

公式（Player.cpp:58-81）：`expToUp = 15 + 8*level`（≤39 级）；`+ 3*(level-39)²`（≥40 级）。属性增量 1~39 级固定 HP+6/攻+1~2/防+1，40 级起随超出幅度递增。

| 等级 | 下一级需求 exp | 累计 exp(0→L) | 裸装属性 |
|---|---|---|---|
| 1 | 23 | 23 | HP31 ATK4~9 DEF1 |
| 10 | 95 | 590 | HP85 ATK13~27 DEF10 |
| 20 | 175 | 1,980 | HP145 ATK23~47 DEF20 |
| 30 | 255 | 4,170 | HP205 ATK33~67 DEF30 |
| 39 | 327 | 6,825 | HP259 ATK42~85 DEF39 |
| 40 | 338 | 7,163 | HP266 ATK43~87 DEF40 |
| 50 | 778 | 12,468 | HP391 ATK55~116 DEF52 |
| 60 | 1,818 | 25,473 | HP616 ATK77~165 DEF74 |

**结论：曲线设计合理、不肝。** 0→60 总需求 25,473 exp，按各段可打怪平均经验折算击杀数约 36~78 只/段（随等级增高单怪经验上升，击杀数反而下降），全程约 330 只怪即可满级。二段"前快后慢"在数值上成立：39→40 仅 +11 exp 需求，40 级后增速明显（50→60 需求占全程 52%）。

### 发现 A-1：普通怪全段无挑战（难度曲线缺失中间层）

**全部 10 个普通怪场景纯攻击胜率 100%**，期望回合仅 2.4~6.4。区域 2（Lv8）打哥布林甚至全程无伤。原因：玩家先手 + 基础属性曲线（每级攻+1~2/防+1）碾压怪物静态数值，区域标配装备下更是碾压。当前"普通怪 = 经验包、Boss = 唯一挑战"的两极结构下，**战斗决策空间被压缩为"无脑攻击"**——与 DEVELOPMENT_JOURNEY 宣称的"构筑驱动 > 数值碾压"理念存在落差（装备提升感知弱，因为不穿装备也能赢）。

**建议（并入 C 报告 P1-4 节奏改善，数据侧依据）**：① 普通怪加入 1~2 个"区域精英怪"（同区数值 ×1.5~2，掉率高）作为梯度；② 或引入 ARCHITECTURE.md 已提出的"随玩家等级动态修正"（按等级窗口比例缩放怪物属性），让同级窗口内存在"打得过但有伤"与"打不过要绕"的决策。

### 发现 A-2（高优先）：最终 Boss 数值断崖，解锁等级即 0% 胜率

**深渊之王在解锁等级 48 时：真实装备（星辰剑）胜率 0.0%，毕业装（魔王裁决）也仅 17.9%**；需刷到 Lv55 才 100% 稳过。7 级窗口内玩家打它必死。叠加后果：
- 死亡惩罚是**全进度丢失**（无自动存档，ARCHITECTURE.md:142 自认），Lv48 玩家误遇 Boss → 大概率死亡 → 数小时进度清零；
- 10% Boss 遭遇率 × 逃跑 50% 成功率，玩家会反复"遇 Boss→跑"，挫败感强。

**建议**：① 降低深渊之王数值 15~20%（HP 1600→1300~1350，ATK 85~105→72~92），使 Lv48~50 毕业装胜率回到 25~40%（有挑战但可翻盘）；② 或在遭遇提示中加入等级建议（"以你当前的等级，挑战深渊之王的胜算极低"），配合 P1-1 自动存档兜底。

### 发现 A-3：新手期过度保护（V5.0 STARTHP 20→25 矫枉过正）

新手第一战（Lv0 兔子）受伤仅 2.8/25，野猪 8.6/25——从 V5.0 前的"打不过野猪"修正为"全程无风险"。DEVELOPMENT_JOURNEY 记录的第一战挫败已解决，但修正过度：0~8 级完全不存在死亡可能，教学感过强。**建议**：恢复部分挑战（STARTHP 22~23 或区域 1 怪物伤害 +1~2），保留"打得过但会掉血"的紧张感。

## ④ 掉落期望与装备经济

- 普通怪单次击杀：85% 药水 / 8% 武器 / 7% 防具 → **期望 0.15 件装备/只**（约 6.7 只掉 1 件装备）。
- Boss 3 连 roll：专属武器权重 70% → **必掉率 1-0.3³ = 97.3%** ✓（复核 ARCHITECTURE.md:65 无误）。
- 装备提升链（武器均值）：匕首 1.0 → 铁剑 3.0 → 精钢剑 5.5 → 符文剑 9.0 → 秘银剑 13.5 → 龙牙剑 19.0 → 星辰剑 25.5；Boss 专属武器同级高约 2~3 倍（野猪王獠牙 4.5 > 匕首 1.0，魔王裁决 45 > 星辰剑 25.5）。

**结论：掉落设计自洽 ✓，且形成"普通怪刷药水/经验，Boss 刷专属武器"的清晰分工——Boss 武器天花板让"刷 Boss"成为装备主路径，这是好的构筑驱动设计。** 潜在问题：① 普通怪装备掉率 8%/7% 偏低，非 Boss 玩家的武器升级进度慢（平均 12.5 只才掉 1 把指定武器），若玩家回避 Boss（怕死），装备会卡在区域普通武器——与 A-2 联动放大 Boss 断崖；② 无稀有度/词条系统（ARCHITECTURE.md:143 已列未来方向），装备提升维度单一。
