# Dongeon 开发感言

> 从一个想法，到一套完整的游戏系统。记录我从"写代码"到"审代码"的转变。

## 起点：为什么是 Dongeon

最开始，我只是想用刚学的 C++ 做一个能跑起来的东西。控制台游戏是最低门槛的选择——不需要美术、不需要引擎，一个终端就能承载全部想象。Dongeon（地牢求生）就这么诞生了：一个中文控制台回合制地牢 RPG。

当时的我对"游戏开发"的理解很朴素：写代码。把语法学会，把逻辑写对，能编译能运行，就满足了。所以我写下了大量 if-else、硬编码的怪物属性、写死的掉落逻辑——**能跑，但很糙**。

## 开发历程：每个版本都是一个问题

**V2.0之前：**也是由于当时我对游戏开发理解朴素的原因，在这个大版本之前，我并没有真正去记录2.0版本之前的开发进度以及相关记录等。完全就是一个文件管理了全部，战斗逻辑，怪物刷新全部塞在一个文件中了。

### V2.x：从"能跑"到"会崩"

- **V2.2 等级限制的怪物刷新**：第一次意识到"玩家体验曲线"这个概念——不能让 1 级玩家遇到 99 级的怪。
- **V2.3 战斗平衡调整**：发现数值是游戏的血肉。药水分类使用、物品类型强枚举——开始用语言特性约束逻辑错误（`enum class` 让"传错类型"在编译期就暴露）。

### V3.0：第一次架构觉醒

这是收获最大的一个版本。把硬编码的掉落改成**数据驱动的掉落表**，给怪物/物品引入**工厂化管理**，把 UI 从主流程里**封装出去**。我学到的最重要一课：

> **不要把所有东西都写在主函数里。** 把"内容"（怪物、物品、掉落）和"逻辑"（战斗、背包、装备）分开，游戏才谈得上扩展。

### V4.1：存档系统

JSON 序列化存档——当时觉得很难（对象怎么变成文件？），做完后豁然开朗：**每个类自己管自己的序列化**，父类组合调用，问题就分解了。这也是我第一次完整走完"设计 → 实现 → 测试 → 记录"的闭环，然后我暂停了开发，觉得"差不多够了"。

## 转折：从"写代码的人"到"审代码的人"

真正让我重新打开这个项目的，是一次直播间的启发。我意识到：**在这个时代，一个人想要做游戏，最该掌握的不是"记住所有语法"，而是"指挥 AI 的能力"**——我能看懂代码、能拆解需求、能验收结果，剩下的重复劳动交给 AI。

Dongeon V5.0 就是这次理念转变的实践。我带着完整的架构分析（哪里是坑、哪里要重做）与 AI 协作完成了重构：

- 数值体系全部重做：二段成长曲线、7 大区域 30 种怪物、Boss 战、完整装备构筑
- 我负责**理解与决策**（分段点选在哪、掉落率定多少、Boss 怎么设计），AI 负责**实现与验证**
- 冒烟测试发现"新手第一战可能打不过"——我们通过实测数据反推修正，而不是拍脑袋调数字

这次经历让我确认了一件事：**AI 不会取代游戏开发者，但会用 AI 的开发者会取代不会用的的程序员。** 我的价值不在写每一行代码，而在知道"游戏应该长什么样，该怎么去设计"。

## 技术收获清单

- **C++ 核心**：继承与多态（物品体系）、智能指针所有权（unique_ptr 管理背包/装备）、移动语义（std::move 转移所有权）、强枚举（enum class 防错）
- **设计模式**：工厂（物品构造）、缓存（配置加载）、多态（开闭原则）、外观（UI 封装）
- **数据驱动**：JSON 配置与代码解耦、权重池掉落数学
- **工程工具**：CMake + Ninja 构建、git 版本管理、Python 自动化冒烟测试（AI 协作后补上的好习惯）

## 游戏设计的领悟

1. **数值是迭代出来的**，不是一次算准的——V5.0 首版"0 级玩家打不过野猪"，实测才发现并修正。先定目标体验（几回合击杀、掉多少血），再反推数值。
2. **反肝度设计**：升级曲线用二段函数——前期快速正反馈，后期厚积薄发，而不是无脑二次方让人刷到吐。
3. **构筑驱动 > 数值碾压**：强度来自装备搭配与选择，不是等级数字膨胀。这也是我最想做的游戏（搜打撤 + 基地经营）的核心信条。
4. **最小侵入式扩展**：Boss 机制 = 一个 bool 标志 + 一个概率判断，玩法就长出来了。小步叠加，永远别推翻重来。

## 下一步

Dongeon 会留在 GitHub 上，作为我 C++ 阶段的里程碑。它的架构资产（数据驱动、物品多态、存档、Boss 机制）将迁移到我用团结引擎（Unity 中国版）开发的下一个项目——2.5D 搜打撤 + 基地建设 + 小队战术。

从控制台到引擎，从一个人到人机协作，游戏开发这条路，才刚刚开始。

以上是我对这一次游戏开发的所有收获与理解，放在这里也是为那些，像我一样，自己一个人摸索着走上这一条路的人提供一些经验。
